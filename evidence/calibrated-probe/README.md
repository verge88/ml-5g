# Сохранённые результаты калиброванной серии

Это синтетические данные. Слово `physical` в некоторых машинных полях означает
один недублированный прогон симулятора в отличие от нескольких оценок его
результата; оно не означает физический сетевой стенд.

Основная серия: https://github.com/verge88/ml-5g/actions/runs/41512395301.
Структурный аудит: https://github.com/verge88/ml-5g/actions/runs/41514333152.

| Файл | Содержание |
|---|---|
| results.json | Сводные результаты, первичный критерий, все дополнительные срезы |
| audit.json | Отдельная проверка записей, бюджета, свежести и статистических границ |
| raw_results.zip | Исходный итоговый Actions-артефакт с per_trace.json, results.json, REPORT.md |
| frozen_models.zip | Исходный артефакт моделей и frozen.json |
| thresholds.json | Зафиксированные до теста пороги и здоровые калибровочные максимумы |
| frozen_thresholds.zip | Исходный артефакт этих порогов |
| frozen_manifest.json | Среда, диапазоны обучения, состав признаков и контрольные суммы |
| calibration_audit_before_test.json | Проверка калибровки до чтения тестового результата |
| passive_equivalence.json | 192 пары структурного контрпримера, отдельная серия |
| calibrated_comparison.png | Сравнительный рисунок первичного режима |

Контрольные суммы исходных архивов:

- raw_results.zip: `67fead69c8a4f7eaabb7d28a68f00821b89630349620299eb19bd2f7c52cd4f6`;
- frozen_models.zip: `ec2920dc1c9a02f7a7bd2f88056053728fcb0e89f7b71ca82021ed2a33e0d902`;
- frozen_thresholds.zip: `4ca649c6787668916f90943eff53212e6df5706c955101d1a162f0b645f22cbd`.

Проверка сохранённого результата после распаковки `raw_results.zip` в
`out/archived-result`:

```
python analysis/audit_calibrated_results.py --input out/archived-result
```

Это проверка артефакта, а не независимое повторение опытов. Полный повтор
производит workflow `calibrated-probe-study.yml` из зафиксированного коммита
`fd98bd6572070ea9289bb07b16dc89cc26827e91`. Критерий совместного успеха
не выполнен; код и данные сохраняют этот отрицательный результат.
