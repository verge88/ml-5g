# Native Open5GS integration

Two separate evidence streams, without changing Open5GS C sources:

1. Build official Open5GS v2.7.6 commit d9d3abdd480be96fac3bc8a997e83446648763ca and run its original registration suite with MongoDB, TUN, native NF child processes and loopback packet capture. This exercises the project's UE/gNB test harness and real core processes, not a physical radio or operator network. The suite is not the security detector benchmark.
2. Three separate NRF/AUSF/NSSF container deployments. Freeze image digests before launch. Capture native HTTP/2 discovery documents and direct GET / responsiveness. Collect chronological normal fit, normal calibration, known stop training, independent normal test and four stop/pause test episodes per deployment. Evaluate a fixed availability rule, robust threshold, Isolation Forest, HGB and feedforward MLP on the same eight live features. Controller event labels never enter features.

Security claim boundary: controlled availability faults are not malicious SBA semantic attacks. A 404 response proves an HTTP/2 listener, not service correctness. Stop and pause share a failure symptom. Recovery observations are reported separately from steady normal FPR. No actual CU is generated by these unmodified images; no external independent witness is installed. The original full CU/witness verifier therefore remains UNKNOWN. This run does not validate the previous synthetic nine-family benchmark, scheduling advantage, mutual TLS, OAuth or malicious NF compromise.

The driver has only fixed loopback endpoints and fixed local Compose service names. It cannot take an external target. There is no traffic flooding, exploit or response-tampering implementation.

Reproduction is through `.github/workflows/native-open5gs.yml`. Artifacts contain raw JSONL HTTP/2 responses, lifecycle events, model scores, thresholds, package versions, image digests, source revision, official suite logs, process list and packet capture. The third-party images are not the official-source build used by the registration suite; those are separate experiments.
