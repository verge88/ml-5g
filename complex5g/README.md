# Более сложные поведенческие сценарии

Новая серия дополняет прежний эксперимент, сохраняя его исходные файлы. Сценарии моделируют совместные зависимости величин, порядок абстрактных операций, связь событий разных NF и локальный контекст разрешённых обновлений. Они не генерируют трафик в действующую сеть и не реализуют полную процедуру 3GPP.

В обычной работе допускаются перезапуски, смена поколения NF, легитимное изменение связей, изменение нагрузки и редкое дублирование событий. Каждому атакующему запуску соответствует нормальная копия с теми же случайными исходными условиями.

Семейства: подмена идентичности; нарушение совместной зависимости с сохранением всех отдельных значений; перестановка операций; рассогласование NF при сохранении локальных частот; редкие перестановки; нарушение порядка на фоне обновления другой NF; изменение связи; сочетание подмены профиля и перестановки; отрицательный контроль без наблюдаемых отличий.

Два поведенческих семейства, рассогласование NF и редкие перестановки, отсутствуют в атакующей обучающей части. Метки для ML относятся к поведению; подмены профиля без изменений телеметрии не получают положительную поведенческую метку. Семейство без наблюдаемых отличий не используется для обучения.

В нормальных данных обучаются зависимости телеметрии, вероятности переходов между операциями, взаимодействия NF и появления связей с учётом локальной фазы обновления. Пороговые методы, Isolation Forest, бустинг и небольшая нейронная сеть получают одинаковые причинные признаки. Простой структурный конкурент использует те же изученные отношения. Новизна связи учитывается явно через вероятность, а не через постоянный в обучении бинарный признак.

Проводятся две отдельные калибровки: 1% по нормальным наблюдениям и 1% по максимумам в нормальных 32-тактовых интервалах. Они имеют разные единицы и остаются эмпирическими целями. Дополнительно публикуются тревоги на нормальной копии каждого атакующего эпизода и разность частот срабатывания между копиями.

Протокол находится в `protocol.json`. Сначала выбранные параметры проверялись только на разработочной инициализации 7; окончательные инициализации 101–110 зафиксированы отдельно. Итог сохраняет показатели всех методов, отрицательные результаты, предупреждения обучения MLP и интервалы по инициализациям. Успех CI не требует преимущества ML.

```sh
python -m complex5g.benchmark --seeds 101 102 103 104 105 106 107 108 109 110
python -m complex5g.aggregate --input results/complex
```

Числа характеризуют контролируемую имитацию: 13 логических позиций NF, 720 тестовых запусков, 360 атакующих эпизодов, включая 40 отрицательных контролей. Свидетельства исполнения и разрешения жизненного цикла предполагаются корректными входами. Аппаратная аттестация, работа всей конструкции на живом ядре и научная новизна этим опытом не доказываются.
