# Проверка пригодности CTD5G для контекстного сравнения

Задача этого этапа — проверить данные до обучения моделей. Используется опубликованный
архив CTD5G версии 1.0, запись Zenodo 15853959. Архив полностью проверяется по опубликованному
MD5; дополнительно рассчитывается SHA-256. Исходные программы генерации трафика не запускаются.

Из архива читаются десять обработанных сегментов штатной коллекции и четыре пары исходных
и обработанных сегментов смешанной коллекции. Число сегментов не считается числом независимых
сеансов. Метки консервативно восстанавливаются из исходных служебных маркеров. Каждый
немаркерный IPv4-пакет сопоставляется с обработанным пакетом по времени и каноническим байтам.
Любое нарушение сопоставления прерывает аудит.

Штатные запросы сортируются по времени. Первые 60% формируют словарь наблюдавшихся связей
и операций. Остальная часть позволяет посчитать законные новые операции. Для смешанной
коллекции подсчитываются размеченные запросы на известных связях, известных операциях
и тех же версиях HTTP. Отдельно учитываются неоднозначные и неразмеченные запросы.

Проверяются остатки маркеров, пересечение MAC-адресов и корректность контрольных сумм по
классам. Эти признаки, идентификаторы процедур и абсолютные даты запрещены для будущей
модели. Токены и адреса не считаются подтверждёнными ролями или полномочиями.

Минимальный исследовательский допуск: хотя бы 20 запросов с меткой атаки на известных
операциях и версиях HTTP, а также хотя бы 20 новых штатных операций в отложенной части.
Это проверка наличия контрастных случаев, а не доказательство превосходства ML.
Одна смешанная коллекция не обеспечивает независимое подтверждение по сеансам.

GitHub Actions публикует только агрегированные результаты, версии и хеши. Пакетные записи,
токены, адреса, необработанные запросы и полезная нагрузка не загружаются в артефакты.
